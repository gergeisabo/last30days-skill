Grok X search no longer floods results with off-topic timelines when keyword search returns thin results. Frequency-extracted handles now require corroboration (explicit `--x-handle`/`--x-related`, or handle matches a topic token) before receiving FROM-lane timeline pulls. Multi-word topics also no longer phrase-quote in all search formulations, allowing posts mentioning topic terms non-adjacently (e.g., "Trevi Fountain in Rome" for a "Rome Italy" search) to be retrieved.
